## UI/UX Test case

**Рівень складності:** базовий.

Необхідно створити дизайн простої сторінки контакту з базовою інформацією про контакт. Сайдбар та інші елементи, відсутні на мокапі, за вибором виконавця, але не є обов’язковими.

### Про концепт

Це звичайна концепція CRM-системи — корпоративного програмного забезпечення для внутрішнього використання в компанії. Має бути зручним та зрозумілим. Це частина дашборду, де є сайдбар. Додатково, але не обов'язково, можете додати можливість виходу з системи (логін/логаут), нотифікації та повідомлення.

### Вимоги до дизайну

Стиль, оформлення, кольорова гамма, UI/UX-елементи та компоненти — на вибір виконавця.

### Вимоги до результату

Результатом має бути файл у Figma або посилання на відповідний прототип у Figma. Дизайн має бути виконаний компонентами та обов'язкова наявність UI Kit.

### Додаткова інформація

Результат завдання не використовуватиметься як готовий продукт або у будь-якому програмному забезпеченні.
